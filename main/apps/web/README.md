# BSLT Web (`@bslt/web`)

Thin React 19 + Vite composition root for the BSLT platform (`foundation-v1`).

## Architecture

- **Services before React:** [main.tsx](./src/main.tsx) constructs `ClientEnvironment` (`config`, `queryCache`, `auth`, `transport`) before `createRoot(...).render(<App environment={environment} />)` so session initialization and token refresh begin immediately.
- **Vertical module composition:** Domain routes, navigation, settings sections, admin surfaces, and `en-US` message catalogs live in `main/modules/*/web` and are aggregated by `@bslt/web-platform` (`createWebApp`) using generated bindings in `src/generated/modules.ts` (`pnpm bslt sync modules`).
- **Four named shells:**
  - `PublicShell` — public marketing, legal, status, support, and moderation notice routes (SSR/prerenderable via `entry-public.tsx` and `serve.ts`).
  - `AuthShell` — login, registration, password reset, email verification, and reactivation flows.
  - `AppShell` — authenticated application chrome with left navigation, unified [SettingsLayout](./src/app/account/SettingsLayout.tsx) (`/profile`, `/settings/*`), and mobile bottom bar.
  - `ConsoleShell` — admin control center (`AdminLayout`) and developer surfaces (`/admin/*`, `/ui-library`).
- **Owned browser stack:** Uses `@bslt/client-engine`, `@bslt/react`, `@bslt/ui`, and `@bslt/web-platform`. The only third-party runtime dependencies are `react` and `react-dom`.

## Commands

```sh
pnpm --filter @bslt/web dev        # Vite dev server (proxies /api -> localhost:8080)
pnpm --filter @bslt/web build      # Client bundle + public SSR bundle + static prerender
pnpm --filter @bslt/web type-check # TypeScript strict check
pnpm --filter @bslt/web test       # Vitest unit suite
pnpm --filter @bslt/web lint       # ESLint (zero warnings, jsx-a11y)
```

## Directory Layout

```text
main/apps/web/src/
├── main.tsx                # Client entrypoint (services before React)
├── entry-public.tsx        # Public-only SSR renderer for prerendering & live public routes
├── serve.ts                # Production Node 24 web server (PROCESS_ROLE=web)
├── config.ts               # Runtime/build-time client configuration
├── generated/              # Generated by `pnpm bslt sync modules`
└── app/
    ├── App.tsx             # Root providers, query persistence, consent banner, ToS modal
    ├── routes.tsx          # Frame route contributions + shell wiring
    ├── frame.ts            # App-frame nav, palette, and theme settings metadata
    ├── account/            # Unified SettingsLayout, SettingsPage, ProfilePage, Preferences
    ├── admin/              # AdminLayout, AdminDashboardPage, admin surface registry
    ├── dashboard/          # Authenticated DashboardPage
    ├── shells/             # PublicShell, AuthShell, AppShell, ConsoleShell, ShellHeader
    └── pages/              # LandingPage, ForbiddenPage, UnavailablePage, NotFoundPage
```
