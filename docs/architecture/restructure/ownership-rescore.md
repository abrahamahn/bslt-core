# Stack review re-scored under the ownership rule

Owner decision (2026-11-10): **own all runtime code except React.** Replace every third-party runtime npm package with owned code on Node built-ins / Web platform APIs; keep `react`/`react-dom`; dev tooling exempt; enforce with a CI allowlist audit. Infrastructure software you configure (Postgres, Redis/Valkey server, ffmpeg binary, Caddy, Linux, Docker) is allowed. External services are allowed only behind ports owned in the codebase, called over their HTTP/standard protocols — no vendor SDK packages.

Source: `stack-review.md` (same folder). Its verdicts stand except where listed here.

## Recommendations that do not change

Everything in `stack-review.md` that is about architecture, data model, vendors, compliance, or operations stands: real RLS, process roles, rolling deploys, ledger + entitlements + Money contract, payment ingress port, realtime hardening, storage upload sessions and delivery signing, media state machine and metadata stripping, trust & safety and age-assurance ports, audience-rating mechanism, public-route SSR seam (owned, React `renderToString`/`hydrateRoot` only), Postgres full-text search, analytics partitions, observability, Node 24 everywhere, server-rust extraction (owner's call), vendor selections and the legal/compliance gaps.

## Full runtime replacement list for bslt-main (foundation)

Small first: `pino`, `pino-pretty`, `@fastify/compress` (`node:zlib`), `otpauth` (RFC 6238), `argon2` (`crypto.argon2`, built into Node 24.21), `nodemailer` (reuse comms SMTP client), `@sentry/react` (own error endpoint), `@fastify/swagger(-ui)` (OpenAPI from contracts), `stripe`/`@stripe/*` (REST + hosted checkout).
Then: `@aws-sdk/*` (SigV4 S3 client), `ws` (RFC 6455), `web-push` (VAPID + RFC 8291), `ioredis` (RESP client), `sharp` (ffmpeg).
Last: `fastify` + `fastify-plugin` (owned router on `node:http`, contract-driven), `@simplewebauthn/*` (CBOR/COSE verification on `node:crypto`), `postgres` (owned wire-protocol client: SCRAM-SHA-256, extended query, pooling, LISTEN/NOTIFY, timeouts, retries) — each behind conformance tests (RFC vectors, Autobahn, real-DB suite).
Kept: `react`, `react-dom`. Dev tooling exempt.
